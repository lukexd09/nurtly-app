# Nurtly – ChatGPT Project Context

Status: Knowledge Base v1  
Confidence: Medium-High  
Last updated: 2026-05-31

## Purpose

This file is a compact context document for AI agents, coding assistants, RAG systems, and future ChatGPT sessions working on Nurtly.

It should provide enough context to prevent agents from treating the project as a generic parenting app.

## Project Name

Nurtly

Important note:

The architecture should remain rebrand-friendly. The name may need to change if trademark, store, or market issues appear.

## Product Type

Mobile application for parents and caregivers.

## Target Users

Adults, especially parents and caregivers of children aged 0–6.

Children are not users of the app.

## Product Direction

Nurtly is a calm parenting companion.

It helps parents:

- organize daily care
- reduce mental load
- discover play ideas
- use calming sounds
- build simple routines

## Core Areas

### Home

Calm entry point. Should show what matters without clutter.

### Journal

Daily care logging and observations. Important MVP candidate.

### Play

Curated activity ideas for parents and children.

### Sounds

Calming audio experiences for routines, relaxation, sleep preparation, and background ambience.

## Tone

The product should feel:

- calm
- warm
- supportive
- premium
- trustworthy
- practical
- parent-oriented

Avoid:

- childish UI
- medical tone
- gamification
- aggressive engagement
- dark patterns
- excessive dashboards
- AI hype language

## Key Product Assumptions

- Parents are users.
- Children are not users.
- Privacy should be designed in from the beginning.
- Child name should not be mandatory.
- Date of birth should not be mandatory unless a feature clearly requires it.
- Minimal data collection is preferred.
- AI should not be front-and-center in positioning.
- English and Polish are important languages.
- MVP should remain focused and launchable.

## Current MVP Thinking

High-confidence MVP candidates:

- calm Home screen
- basic Journal / care logging
- Sounds module with calming audio
- simple Play module with activity ideas
- privacy-conscious onboarding
- basic store readiness

Areas likely to need more definition:

- exact Journal fields
- account model
- local vs cloud storage
- monetization timing
- content management approach
- analytics events
- subscription model
- AI feature scope

## Design Direction

Sound cover artwork and app visuals should be adult-oriented and calming.

Preferred style:

- soft atmospheric digital illustration
- editorial wellness aesthetic
- muted sage green
- warm off-white
- soft grey-blue
- gentle beige
- minimal clutter
- no harsh contrast
- no child-facing cartoon style

For sound artwork:

- no text
- no logos
- no UI
- no people
- no babies
- no children
- no cartoon animals
- no music notes
- no headphones
- no speaker icons

## Known Sound Concepts

Existing or planned calming sound artwork concepts include:

- Soft rain
- Warm noise
- Quiet stream
- Evening crickets
- Room fan
- Dishwasher hum

The audio module should support a calm mobile audio player experience.

## Product Positioning

Nurtly should not be positioned as:

- medical advice
- diagnosis
- therapy
- child development authority
- social platform
- AI-first product

It should be positioned as practical support for daily parenting.

## Important Working Style

When working on Nurtly:

1. Prefer small, shippable increments.
2. Preserve calm design direction.
3. Do not add complexity without clear value.
4. Keep privacy implications visible.
5. Update the knowledge base when product decisions change.
6. Treat this file as quick context, not the full source of truth.
