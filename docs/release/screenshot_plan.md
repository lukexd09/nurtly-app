# Screenshot plan

This is a planning brief for Google Play screenshots. Use actual in-app captures.

## Constraints

- Show the real in-app experience.
- Avoid misleading claims, awards, rankings, price promos, or old screenshots.
- Avoid dense small text.
- Keep the first screenshots focused on the actual UI.
- Use localized overlays if overlays are added.
- Match the final store language variants.

## Proposed set: 6 phone portrait screenshots

### 1. Home / calm start

- Screen to capture: Home screen.
- Purpose: Show the calm entry point and overall product mood.
- Suggested PL overlay: Spokojny start dnia
- Suggested EN overlay: A calm start
- Must be visible: Home cards, navigation, brand feel.
- Must not be visible: Debug labels, promotions, clutter.
- Alt text PL: Ekran startowy Nurtly z kartami spokojnych pomysłów i dźwięków.
- Alt text EN: Nurtly home screen with calm idea and sound cards.
