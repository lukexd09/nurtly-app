# Feature graphic brief

## Required specs

- Size: 1024 x 500 px
- Format: JPEG or 24-bit PNG, no alpha

## Concept

Create a premium, calming, parent-facing visual for Nurtly.

Theme ideas:

- warm evening routine,
- soft natural or home ambience,
- calm daily support for parents,
- refined abstract comfort rather than literal clutter.

## Visual direction

- muted sage green,
- warm off-white,
- soft grey-blue,
- beige,
- gentle contrast,
- no busy background,
- no harsh neon,
- no clinical styling.

## Composition

- Keep the key visual centered.
- Avoid important details near the edges.
- The graphic should still work if the text is removed.
- Leave room for crop safety across different Play surfaces.

## Text guidance

- Prefer no text if possible.
- If text is used, keep it short and localized per market.
- Avoid claims like best, new, free, discount, or download now.
- Avoid medical or sleep-guarantee language.

## Asset QA checklist

- [ ] Image is 1024 x 500 px.
- [ ] File is JPEG or 24-bit PNG without alpha.
- [ ] Visual reads clearly at small sizes.
- [ ] No child faces or medical framing.
- [ ] No promotional claims or discount text.
- [ ] No clutter near crop edges.
- [ ] Tone matches a calm parenting app.
