# Store assets checklist

- [ ] App icon is 512 x 512 PNG with alpha and under 1024 KB.
- [ ] Feature graphic is 1024 x 500 JPEG or 24-bit PNG with no alpha.
- [ ] Phone screenshots are prepared, ideally 4-8 images.
- [ ] Screenshot localization is prepared for PL and EN if overlays are used.
- [ ] Alt text is prepared for each asset and stays under 140 characters.
- [ ] No misleading claims appear in screenshots or graphics.
- [ ] No ranking or performance claims appear in assets.
- [ ] No price or discount promo text appears in assets.
- [ ] No Google Play badges are used in the visuals.
- [ ] No third-party trademarks are used without permission.
- [ ] Status bars and notification clutter are cleaned up where appropriate.
- [ ] Assets match the actual MVP UI.
