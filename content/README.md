# Content

This folder is reserved for editorial and publishing workspace materials.

For the current MVP, the runtime content used by the app is bundled under:

- `app/assets/content/nurtly_content_en_v1.json`
- `app/assets/content/nurtly_content_pl_v1.json`

Do not assume files in `content/` are loaded by the app unless they are explicitly wired into the app content pipeline.
